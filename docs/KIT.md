# Reusable kit

These pieces came from the Webex lab kit and were retargeted for Teams Phone. Copy them into another lab, then change the section list, the repo URL, and the lesson data.

| Piece | Role |
| --- | --- |
| `assets/css/canon.css`, `shell.css`, `wow.css`, `frame.css`, `polish.css`, `footer.css`, `university.css` | Page chrome, themes, footer, phone dock |
| `assets/css/round2.css` | Banner row, monkey, bottom sheet, contrast fixes. Load this last |
| `assets/js/frame.js`, `university.js`, `phone-nav.js`, `wow.js` | Banner, menu, dock, theme |
| `assets/js/round2-bot.js` | Tour, greeting modal, docked monkey, read-along, voice |
| `scripts/build_round2.py` | Rooms, diagrams, sheets, zip from `campus/data` |
| `scripts/gzip-static.mjs` | Local gzip server for Lighthouse |
| `sw.js`, `manifest.webmanifest` | Installable offline shell |

Keep the three brand links only: the website, the GitHub organization, and `https://linktr.ee/cypherMonkey`. The disclaimer box is required on every page and every download.
