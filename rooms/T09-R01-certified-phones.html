09 · Devices and media

Certified phones

A bargain SIP phone is not a Teams client. The certified list is the product boundary.

Room HTMLAll downloads

5 minutes · Visual · Example · Quiz · Sources · Ecosystem

Learn it in 5 minutes

Teams-certified phones sign in as Teams users and use the Teams media stack. SIP Gateway covers a smaller set of compatible SIP and analog devices, with a smaller feature list. Check the current list before you buy.

QoS for phones follows the same DSCP story, with device-specific notes in the rooms and devices articles. A phone that never registers is often identity or Conditional Access, not a codec.

Use Teams-certified phones or the SIP Gateway device list. Do not invent a third category.

Quiz

Which description of Teams Rooms license is accurate?

Rooms use their own SKU family, not a borrowed user Calling Plan. Names such as Basic and Pro change. Check the current name. A room that cannot join is often a license or a resource account, not a codec. Source: https://learn.microsoft.com/en-us/microsoftteams/teams-phone-licensing accessed 2026-10-14.

A colleague reports: The room account has a user E5 stack and still fails sign-in policy. Where do you start?

The room account has a user E5 stack and still fails sign-in policy. Assign the current room license to the room account and keep Conditional Access from blocking the device. Source: https://learn.microsoft.com/en-us/microsoftteams/teams-phone-licensing accessed 2026-10-14.

Which description of Media bypass is accurate?

Media can flow between the Teams client and the SBC, skipping Microsoft’s media processors. Signaling still goes through Teams. People hear ‘bypass’ and think the SBC talks to Teams with no SIP proxy. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Glossary

  • Teams Rooms license Rooms use their own SKU family, not a borrowed user Calling Plan. Names such as Basic and Pro change. Check the current name. Config: Assign the current room license to the room account and keep Conditional Access from blocking the device. Fault: The room account has a user E5 stack and still fails sign-in policy.
  • Media bypass Media can flow between the Teams client and the SBC, skipping Microsoft’s media processors. Signaling still goes through Teams. Config: Enable it on the gateway only when the client can reach the SBC and LBR does not forbid the path. Fault: Bypass is on for a VPN user and audio is worse than the processor path.
  • Local media optimization A Direct Routing pattern with internal and external SBC interfaces so a branch user stays on the local media path. Config: Use the current media optimization article and the SBC vendor’s build. Fault: Internal users hairpin out to the internet and back to the SBC on the same LAN.
  • SIP Gateway Microsoft’s front end for certain compatible analog and SIP devices that are not Teams phones. Config: Check the current supported device list before you buy handsets. Fault: A generic analog adapter is plugged in and never registers.

Cross-platform bridges

CUCM

Cisco CUBE is one of the SBC families named in this lab’s certification lesson. A certified release can be the Direct Routing SBC between Unified CM and Teams.

The tenant still needs a verified domain on the SBC FQDN, and the user still needs Teams Phone. The studio translator does not open a live AXL session. Confirm the current certified release before you build.

Webex

Teams Phone and Webex Calling are separate clouds. This lab does not describe a feature that registers a Webex Calling user into a Teams tenant.

A number move is usually a carrier port, a certified SBC, or a meetings interop product. Confirm before relying.

UCCE

Unified CCE stays the ACD until you migrate it. Microsoft’s contact-center articles name Connect, Extend, and Unify. They do not name a UCCE connector in the notes this lab cites.

Voice into Teams is still Direct Routing or Operator Connect. The routing script stays on the contact-center product you bought. Confirm the vendor’s current model. Source: https://learn.microsoft.com/en-us/microsoftteams/teams-contact-center.

Future hooks

Copilot Studio, Azure Communication Services, and Graph are later tracks in this lab. Treat any uncited limit as confirm before relying.
