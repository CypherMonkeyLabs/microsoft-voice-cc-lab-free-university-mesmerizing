Which description of Microsoft 365 tenant is accurate?

The boundary that holds Entra ID, licenses, Teams policies, and verified domains for one organization. An SBC paired in the wrong tenant is a different phone system. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of Pay-as-you-go Calling Plan is accurate?

A Calling Plan billed on use. Also the funding pattern, with communications credits, for some voice-app outbound calls. External transfers from a queue are not free just because users have Direct Routing. Source: https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-prerequisites-licensing accessed 2026-10-14.

Which description of Operator Connect is accurate?

A certified carrier manages PSTN for you inside the tenant. You need Teams Phone. You do not need a Microsoft Calling Plan or your own SBC. It is the low-operations option when your carrier is in the program. Source: https://learn.microsoft.com/en-us/microsoftteams/operator-connect-plan accessed 2026-10-14.

Which description of Voice routing policy is accurate?

The per-user list of PSTN usages, in order. Teams walks that order when it looks for a route. Granting the wrong policy is the most common ‘the SBC is broken’ ticket. Source: https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14.

Which description of Direct Routing emergency is accurate?

You, the SBC, and the carrier deliver the emergency call. Microsoft does not become the emergency carrier because Teams is the client. PIDF-LO may be present. The carrier still has to accept the call. Source: https://learn.microsoft.com/en-us/microsoftteams/what-are-emergency-locations-addresses-and-call-routing accessed 2026-10-14.

Which description of Call Analytics is accurate?

The per-user, per-call quality view in the Teams admin center. Use it when one person had one bad call. It will not explain a building. That is CQD. Source: https://learn.microsoft.com/en-us/microsoftteams/use-call-analytics-to-troubleshoot-poor-call-quality accessed 2026-10-14.

Which description of Connect model is accurate?

A certified contact center attaches to Teams through certified SBCs and Direct Routing. Microsoft’s note: the contact-center agent does not need a phone-system license for that solution; a Teams user who receives a transfer does. Source: https://learn.microsoft.com/en-us/microsoftteams/teams-contact-center accessed 2026-10-14.

Which description of Recognize step is accurate?

The Call Automation action that collects DTMF or speech. It needs a timeout and a path for ‘none of the above.’ A recognize step without an escape traps the caller. Source: https://learn.microsoft.com/en-us/azure/communication-services/concepts/call-automation/call-automation accessed 2026-10-14.

Which description of Passing score 700 is accurate?

Microsoft role-based exams, including MS-700 and AB-250, require 700 out of 1000. A practice percentage is not the same scale unless the practice says so. Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ms-700 accessed 2026-10-14.

Which description of Call-ID is accurate?

The SIP header that identifies one dialog. It is the join key between an SBC capture, a carrier ticket, and a CRM note. A timestamp is not an identifier. Two calls start in the same second. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of Early offer is accurate?

Teams Direct Routing presents media in the INVITE. An SBC or CUBE that waits for a delayed offer will negotiate badly. 488 and one-way audio show up when the offer model is wrong. Source: https://www.cisco.com/c/en/us/products/unified-communications/unified-border-element/index.html accessed 2026-10-14.

Which description of Evaluation form is accurate?

The QM scorecard. It should cite behaviors you can hear, not vibes. A form that scores ‘professionalism’ without a definition will not survive an argument. Source: https://learn.microsoft.com/en-us/microsoftteams/teams-recording-policy accessed 2026-10-14.

Which description of DTMF relay is accurate?

Digits in the audio path or as telephone-events. IVRs fail when the SBC strips them. A human can talk and the bot never hears 1. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of Music on hold is accurate?

The audio a queue plays while a caller waits. Licensing and the file both matter, and silence is a choice you should make on purpose. Callers who hear nothing hang up, and abandon looks like a staffing crisis. Source: https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-call-queue accessed 2026-10-14.

Which description of G.711 law is accurate?

A-law and μ-law are both G.711. A trunk that offers the wrong one still often interoperates, and sometimes does not. Offer both if the carrier is vague. This is a one-line SBC change, after you have a capture. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of Exam sandbox is accurate?

Microsoft’s practice UI for what an exam looks like. It is not the product lab. Use it so the tool is not a surprise. Still study the skills. Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ms-700 accessed 2026-10-14.

Which description of Caller ID substitution is accurate?

Presenting a service number instead of a personal mobile. It is a policy, not a hope. Wrong caller ID breaks return calls and CRM trust. Source: https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14.

Which description of SBA registration is accurate?

Clients must be able to use the appliance when the cloud path is gone. An appliance with no client configuration is a spare server. Read the current SBA article for how clients select it. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-survivable-branch-appliance accessed 2026-10-14.

Which description of Subnet dimension is accurate?

CQD’s subnet field is only useful if you built the building map from real subnets. A typo relocates a building. Source: https://learn.microsoft.com/en-us/microsoftteams/cqd-what-is-call-quality-dashboard accessed 2026-10-14.

Which description of Rollback route is accurate?

The old path left in place so numbers can return. Deleting it is not a cleanup. It is the removal of the safety. Keep it until the new path has a quiet week. Source: https://www.cisco.com/c/en/us/products/unified-communications/unified-border-element/index.html accessed 2026-10-14.

Which description of Dispatchable location is accurate?

A location specific enough for a responder to find the caller. A city name is not enough for a campus. Floors and suites matter. Source: https://learn.microsoft.com/en-us/microsoftteams/what-are-emergency-locations-addresses-and-call-routing accessed 2026-10-14.

Which description of Privacy review is accurate?

Recording, desktop capture, and directory search all need a privacy decision before go-live. A surprise recorder fails the review in public. Source: https://learn.microsoft.com/en-us/microsoftteams/teams-recording-policy accessed 2026-10-14.

A colleague reports: A runbook still says contoso.com in production. Where do you start?

A runbook still says contoso.com in production. Use them only as shapes for a design. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of New-CsTenantDialPlan is accurate?

Creates a tenant dial plan that holds normalization rules. Confirm the parameter set with Get-Help in the module version you have. Interviewers ask for the object model more than for a memorized script. A wrong parameter against production is not a lab. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.
