Which description of Microsoft 365 tenant is accurate?

The boundary that holds Entra ID, licenses, Teams policies, and verified domains for one organization. An SBC paired in the wrong tenant is a different phone system. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

A colleague reports: Overflow to a mobile number fails and the user Calling Plan is blamed. Where do you start?

Overflow to a mobile number fails and the user Calling Plan is blamed. Fund the resource account when the attendant or queue sends calls to an external number, uses callback, or places on-behalf calls. Source: https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-prerequisites-licensing accessed 2026-10-14.

Which description of Operator Connect for India is accurate?

The India-specific operator model. It exists because India PSTN rules are not the same as a generic Operator Connect deployment. A global design that ignores it will fail a regulatory review. Source: https://learn.microsoft.com/en-us/microsoftteams/operator-connect-plan accessed 2026-10-14.

A colleague reports: Both gateways are priority 1 and nobody knows which one took the call. Where do you start?

Both gateways are priority 1 and nobody knows which one took the call. Put the local SBC first and a remote SBC second, then pull the cable in a maintenance window. Source: https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14.

Which description of Location-based routing is accurate?

Stops a user in a regulated site from placing a PSTN call through a gateway in another site. It is a toll-bypass control. Media bypass can fight it if media would egress in the wrong place. Source: https://learn.microsoft.com/en-us/microsoftteams/location-based-routing-plan accessed 2026-10-14.

A colleague reports: The ticket says ‘Teams is down’ and loss is 0.2% with a 600 ms RTT. Where do you start?

The ticket says ‘Teams is down’ and loss is 0.2% with a 600 ms RTT. Capture at the egress and compare with CQD. Source: https://learn.microsoft.com/en-us/microsoftteams/cqd-what-is-call-quality-dashboard accessed 2026-10-14.

Which description of Teams Phone extensibility is accurate?

A way for a contact center, including Dynamics 365 Contact Center, to use a customer’s existing Teams Phone for the agent’s telephony. It is not a second carrier hidden in the app. Source: https://learn.microsoft.com/en-us/azure/communication-services/concepts/interop/tpe/teams-phone-extensibility-overview accessed 2026-10-14.

A colleague reports: A model change ships to the IVR with no eval. Where do you start?

A model change ships to the IVR with no eval. Evaluate a prompt against a test set before you put it on a phone number. Source: https://learn.microsoft.com/en-us/azure/ai-foundry/ accessed 2026-10-14.

Which description of Existing calls are unaffected is accurate?

When you grant a compliance recording policy, calls and meetings already up are not swept in. Test with a new call. A pilot that reuses an open meeting proves nothing. Source: https://learn.microsoft.com/en-us/powershell/module/teams/new-csteamscompliancerecordingpolicy?view=teams-ps accessed 2026-10-14.

A colleague reports: E911 says London, CQD says VPN, LBR says Manchester. Where do you start?

E911 says London, CQD says VPN, LBR says Manchester. Give one team the edit right and publish the list. Source: https://learn.microsoft.com/en-us/microsoftteams/what-are-emergency-locations-addresses-and-call-routing accessed 2026-10-14.

Which description of Vendor-first support is accurate?

Microsoft’s Direct Routing support boundary: you call the SBC vendor, they escalate to Microsoft if they must. Non-certified SBCs can be refused. Opening a Microsoft case with a homemade SBC wastes the outage. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-border-controllers accessed 2026-10-14.

A colleague reports: Every item requires a skill nobody has, so the queue never assigns. Where do you start?

Every item requires a skill nobody has, so the queue never assigns. Attach skills to people and to the classification rules, then test a miss. Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-250 accessed 2026-10-14.

Which description of Browser join ports is accurate?

People who join meetings in a browser do not use the fixed 50000-range client ports. An ACL that only matches those ports misses them. QoS designs that ignore browsers miss a real population. Source: https://learn.microsoft.com/en-us/microsoftteams/qos-in-teams accessed 2026-10-14.

A colleague reports: A script from last year removes a number. Where do you start?

A script from last year removes a number. Get-Help cmdlet -Parameter * in the lab. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of Certified list changes is accurate?

The list of SBCs and contact-center solutions changes. A campus page is not the list. Quote the list the week you buy. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-border-controllers accessed 2026-10-14.

A colleague reports: The SBC demands a client certificate Teams is not presenting in the mode you chose. Where do you start?

The SBC demands a client certificate Teams is not presenting in the mode you chose. Match the SBC setting to what you intended. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of Greeting rights is accurate?

The audio file must be one you have the right to play. A popular song is not a free hold track. Licensing the song is a legal problem, not a Teams setting. Source: https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-call-queue accessed 2026-10-14.

A colleague reports: Two engineers compare two different INVITEs. Where do you start?

Two engineers compare two different INVITEs. Copy it into the ticket and the CRM. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.

Which description of DTMF zero is accurate?

The usual human escape. It has to be implemented, not merely printed on a slide. Test it after every prompt edit. Source: https://learn.microsoft.com/en-us/azure/communication-services/concepts/call-automation/call-automation accessed 2026-10-14.

A colleague reports: Agents look available in Teams during after-call work. Where do you start?

Agents look available in Teams during after-call work. Feed the contact-center state to WFM. Source: https://learn.microsoft.com/en-us/dynamics365/contact-center/ accessed 2026-10-14.

Which description of IVR range split is accurate?

Contact-center numbers stay on UCCE. User numbers go to Teams. The SBC enforces the split. One route pattern that sends everything to Teams strands the IVR. Source: https://www.cisco.com/c/en/us/products/unified-communications/unified-border-element/index.html accessed 2026-10-14.

Which description of Emergency both ways is accurate?

You care that the emergency call leaves, and that the location and notification are correct. Inbound to the queue is a different test. Do not mix the evidence. Source: https://learn.microsoft.com/en-us/microsoftteams/what-are-emergency-locations-addresses-and-call-routing accessed 2026-10-14.

A colleague reports: A plan is activated before any indicator exists in the quality library. Where do you start?

A plan is activated before any indicator exists in the quality library. The page names the Omnichannel Administrator role, plus consumption-based billing and capacity. It says not to use the feature for employment decisions. Source: https://learn.microsoft.com/en-us/dynamics365/contact-center/administer/configure-quality-coach accessed 2026-10-14.

Which description of Grant-CsOnlineVoiceRoutingPolicy is accurate?

Assigns a voice routing policy to a user. Confirm the parameter set with Get-Help in the module version you have. Interviewers ask for the object model more than for a memorized script. A wrong parameter against production is not a lab. Source: https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14.
