Glossary core

Glossary sheet. Definitions are the campus teaching lines, not a vendor glossary copy.

Accessed 14 October 2026. Open the in-app glossary for the config note and the fault.

 

Microsoft 365 tenant — The boundary that holds Entra ID, licenses, Teams policies, and verified domains for one organization.

Verified domain — A domain added and proven in the tenant. Direct Routing SBC FQDNs must live on one of these domains.

onmicrosoft.com domain — The default tenant domain. It is not a supported domain for a Direct Routing SBC FQDN.

Homed online — Direct Routing users must be homed in Microsoft 365, not left on a Skype for Business on-premises registrar.

Islands mode — A coexistence mode. Direct Routing is not supported for users in Islands mode.

Entra ID — The identity directory for the tenant. Teams users, resource accounts, and admin roles are Entra objects.

Resource account — A disabled-for-sign-in Entra account that represents an auto attendant or a call queue. It is not a human login.

Cloud Voicemail — The Teams voicemail service. It deposits messages in the user’s Exchange mailbox.

Teams Phone — The license capability that lets a user use Teams as a phone system. It is not, by itself, a PSTN carrier.

Calling Plan — A Microsoft-operated PSTN option. Domestic, international, and pay-as-you-go are the usual flavors. It is an extra license on top of Teams Phone.

Audio Conferencing — The license that provides dial-in numbers for meetings. It is not Teams Phone.

Teams Premium — An add-on for advanced meetings and related features. It does not replace Teams Phone or a Calling Plan.

Teams Phone Resource Account license — The license each auto attendant or call queue resource account needs, even when the account has no phone number. Subscriptions with Teams Phone include a zero-cost allotment you still have to acquire.

Pay-as-you-go Calling Plan — A Calling Plan billed on use. Also the funding pattern, with communications credits, for some voice-app outbound calls.

Communications credits — A balance used when a call is not covered by a Calling Plan minute. Voice apps use it for some outbound cases.

Shared Calling — A pattern where users place outbound PSTN calls through a resource account’s number instead of each having a number.
