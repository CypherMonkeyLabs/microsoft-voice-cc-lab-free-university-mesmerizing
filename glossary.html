Microsoft 365 tenant

The boundary that holds Entra ID, licenses, Teams policies, and verified domains for one organization.

Config: Confirm the tenant before you run Connect-MicrosoftTeams.

Fault: Two engineers edit two tenants and each thinks the other broke the trunk.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Verified domain

A domain added and proven in the tenant. Direct Routing SBC FQDNs must live on one of these domains.

Config: Add the domain, including a sip subdomain, before you pair the gateway.

Fault: Pairing fails because sbc.contoso.com was never verified.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

onmicrosoft.com domain

The default tenant domain. It is not a supported domain for a Direct Routing SBC FQDN.

Config: Use a domain you verified, such as contoso.com.

Fault: The gateway object is rejected or never becomes healthy.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Homed online

Direct Routing users must be homed in Microsoft 365, not left on a Skype for Business on-premises registrar.

Config: Check the user’s registrar before you assign a voice routing policy.

Fault: The policy is assigned and the call never leaves the legacy system.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Islands mode

A coexistence mode. Direct Routing is not supported for users in Islands mode.

Config: Move the user to a supported mode before you test PSTN.

Fault: PSTN fails only for the Islands users and nowhere else.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Entra ID

The identity directory for the tenant. Teams users, resource accounts, and admin roles are Entra objects.

Config: Create the user or resource account here, then license it, then grant policies.

Fault: A resource account exists in Teams and has no license because nobody looked in Entra.

https://learn.microsoft.com/en-us/microsoftteams/using-admin-roles accessed 2026-10-14

Resource account

A disabled-for-sign-in Entra account that represents an auto attendant or a call queue. It is not a human login.

Config: Create it with a Teams admin role and the User Administrator role.

Fault: Agents try to sign in as the queue and the sign-in is correctly blocked.

https://learn.microsoft.com/en-us/microsoftteams/aa-cq-manage-resource-accounts accessed 2026-10-14

Cloud Voicemail

The Teams voicemail service. It deposits messages in the user’s Exchange mailbox.

Config: Confirm the mailbox and the voicemail policy before you debug the SBC.

Fault: Callers hear a greeting failure and the SBC trace is clean.

Cloud Voicemail — confirm — last checked 2026-10. Did not open when checked.

Teams Phone

The license capability that lets a user use Teams as a phone system. It is not, by itself, a PSTN carrier.

Config: Assign Teams Phone, then add a connectivity option.

Fault: Outbound PSTN fails because only Teams, not Teams Phone, is assigned.

https://learn.microsoft.com/en-us/microsoftteams/teams-phone-licensing accessed 2026-10-14

Calling Plan

A Microsoft-operated PSTN option. Domestic, international, and pay-as-you-go are the usual flavors. It is an extra license on top of Teams Phone.

Config: Buy the plan only where Microsoft sells it, and assign it to the user.

Fault: A user in an unsupported country is given a Calling Plan SKU that cannot be used.

https://learn.microsoft.com/en-us/microsoftteams/calling-plans-for-office-365 accessed 2026-10-14

Audio Conferencing

The license that provides dial-in numbers for meetings. It is not Teams Phone.

Config: Assign it to people who must publish a dial-in number.

Fault: Conference dial-out hits the SBC and the carrier bill surprises finance.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Teams Premium

An add-on for advanced meetings and related features. It does not replace Teams Phone or a Calling Plan.

Config: Buy it only for the meeting features you actually need.

Fault: A design removes Calling Plans because Premium was purchased.

https://learn.microsoft.com/en-us/microsoftteams/teams-add-on-licensing/microsoft-teams-add-on-licensing accessed 2026-10-14

Teams Phone Resource Account license

The license each auto attendant or call queue resource account needs, even when the account has no phone number. Subscriptions with Teams Phone include a zero-cost allotment you still have to acquire.

Config: Assign this license. If you swap off Teams Phone Standard, remove and add in the same license change.

Fault: Queues die after a two-step license swap.

https://learn.microsoft.com/en-us/microsoftteams/teams-add-on-licensing/virtual-user accessed 2026-10-14

Pay-as-you-go Calling Plan

A Calling Plan billed on use. Also the funding pattern, with communications credits, for some voice-app outbound calls.

Config: Fund the resource account when the attendant or queue sends calls to an external number, uses callback, or places on-behalf calls.

Fault: Overflow to a mobile number fails and the user Calling Plan is blamed.

https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-prerequisites-licensing accessed 2026-10-14

Communications credits

A balance used when a call is not covered by a Calling Plan minute. Voice apps use it for some outbound cases.

Config: Fund the balance and assign it where the prerequisite article requires it.

Fault: The queue worked in the pilot week and stopped when the credit ran out.

https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-prerequisites-licensing accessed 2026-10-14

Shared Calling

A pattern where users place outbound PSTN calls through a resource account’s number instead of each having a number.

Config: Read the current shared-calling prerequisites before you promise it to a site.

Fault: Every user was left numberless and the resource account was never funded.

https://learn.microsoft.com/en-us/microsoftteams/teams-phone-licensing accessed 2026-10-14

Common area phone

A shared handset. On Direct Routing it does not need a Calling Plan license.

Config: License the device for Teams and the phone scenario you chose, then assign the number.

Fault: A Calling Plan was purchased for every corridor phone on a Direct Routing design.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Teams Rooms license

Rooms use their own SKU family, not a borrowed user Calling Plan. Names such as Basic and Pro change. Check the current name.

Config: Assign the current room license to the room account and keep Conditional Access from blocking the device.

Fault: The room account has a user E5 stack and still fails sign-in policy.

https://learn.microsoft.com/en-us/microsoftteams/teams-phone-licensing accessed 2026-10-14

Conditional Access

Entra policy that can block a phone or a room that is not in the trusted device set.

Config: Exclude or scope device sign-in on purpose. Do not turn Conditional Access off as a test you leave in place.

Fault: Rooms fail on Monday after a security change nobody told voice about.

https://learn.microsoft.com/en-us/credentials/certifications/security-compliance-and-identity-fundamentals/ accessed 2026-10-14

Shortest media path

Microsoft’s network guidance prefers a short path to the Microsoft network, without a proxy in the media path.

Config: Egress Teams media locally. Do not hairpin a branch through a distant data center unless you mean to.

Fault: One city’s CQD is poor and the firewall team finds a proxy.

https://learn.microsoft.com/en-us/microsoftteams/prepare-network accessed 2026-10-14

VPN and real-time media

Microsoft recommends that you avoid sending real-time Teams media through a VPN. QoS on the VPN does not fix the extra delay.

Config: Test a call on the VPN and off it before you blame the carrier.

Fault: Every remote user shows high RTT and the office does not.

https://learn.microsoft.com/en-us/microsoftteams/qos-in-teams accessed 2026-10-14

ExpressRoute is optional

Teams does not require ExpressRoute. Local internet egress is the usual design. If you do use ExpressRoute, follow the current network article rather than assuming media is happier there.

Config: Decide the path, then mark DSCP on the path you actually use.

Fault: Media was forced onto a long private path and RTT jumped.

https://learn.microsoft.com/en-us/microsoftteams/prepare-network accessed 2026-10-14

QoS markers enabled

The Teams admin center setting that allows clients to insert DSCP. Without it, a correct ACL still sees unmarked client traffic from managed endpoints that honor the policy.

Config: Turn the insert-markers setting on, then verify at the WAN edge.

Fault: The network is marked and the clients were never told to mark.

https://learn.microsoft.com/en-us/microsoftteams/qos-in-teams accessed 2026-10-14

Three to five hops

Microsoft’s planning note: keep the client-to-network-edge path short, on the order of three to five hops, and the ISP-to-Microsoft edge short as well.

Config: Draw the path before you buy bandwidth.

Fault: A branch hairpins through HQ and then out, adding hops and delay.

https://learn.microsoft.com/en-us/microsoftteams/qos-in-teams accessed 2026-10-14

Layer-3 G.711

G.711 at 20 ms is 160 bytes of payload plus 40 bytes of IP, UDP, and RTP. That is 80 kbit/s per direction.

Config: Multiply by concurrent calls and by two directions when both ways are busy.

Fault: Thirty calls were planned at 64 kbit/s and the link saturated.

https://learn.microsoft.com/en-us/microsoftteams/qos-in-teams accessed 2026-10-14

Ethernet G.711

Add an 18-byte Ethernet header to the G.711 20 ms packet and the figure is 87.2 kbit/s per direction.

Config: Use 87.2 kbit/s when the policer sees Ethernet.

Fault: The policer drops the header you forgot.

https://learn.microsoft.com/en-us/microsoftteams/qos-in-teams accessed 2026-10-14

Operator Connect

A certified carrier manages PSTN for you inside the tenant. You need Teams Phone. You do not need a Microsoft Calling Plan or your own SBC.

Config: Enable the operator in the admin center and assign the numbers they provide.

Fault: Someone also builds a Direct Routing SBC for the same numbers and the routes fight.

https://learn.microsoft.com/en-us/microsoftteams/operator-connect-plan accessed 2026-10-14

Operator Connect for India

The India-specific operator model. It exists because India PSTN rules are not the same as a generic Operator Connect deployment.

Config: Use the current India plan article and the licensed operator there.

Fault: A UK SBC was proposed as the egress for an India office.

https://learn.microsoft.com/en-us/microsoftteams/operator-connect-plan accessed 2026-10-14

Teams Phone Mobile

The user’s mobile SIM number is also their Teams number, through a certified mobile operator. Teams Phone is required.

Config: Assign the operator number to the user. Do not also treat it as a spare Calling Plan.

Fault: One human has two different caller IDs and the CRM matches neither.

Plan Teams Phone Mobile — confirm — last checked 2026-10. Did not open when checked.

Direct Routing

You connect a certified SBC to Teams and bring your own carrier. Users need Teams and Teams Phone. They must be homed online. Islands mode is not supported.

Config: Pair the FQDN, open 5061, allow media ranges, assign a voice route.

Fault: The SBC is up and the user has no voice routing policy.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Mixing PSTN options

One tenant may use Calling Plans, Operator Connect, Teams Phone Mobile, and Direct Routing at the same time for different users.

Config: Give each population a policy that matches its carrier.

Fault: A mobile user matches a Direct Routing route and hairpins.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

SIP proxies

For commercial Microsoft 365, signal to sip.pstnhub.microsoft.com, then sip2, then sip3, on TCP 5061. GCC High and DoD use different names.

Config: Checked 15 October 2026. Direct Routing SBC signaling and media on the plan page: 52.112.0.0/14 and 52.120.0.0/14. Teams client optimize on the Office 365 URLs page and the worldwide endpoints feed: 52.112.0.0/14 and 52.122.0.0/15. Those lists are not interchangeable.

Fault: A lockdown allows only today’s DNS answer and the trunk fails next week.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Media ports for Direct Routing

UDP 3478–3481 and 49152–53247 between the SBC and the media processors, unless media bypass keeps the media off that path.

Config: Budget at least two media ports per concurrent call on the SBC.

Fault: Calls connect and both sides hear silence.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Media re-targeting

Microsoft does not support changing the media target in the middle of an active Direct Routing call.

Config: Negotiate media at setup and leave it.

Fault: Audio dies when a transfer tries to move the RTP peer.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Two media ports per call

Microsoft’s planning tip: allocate at least two media ports on the SBC for each concurrent call.

Config: Size the SBC media range from the busy-hour call count.

Fault: The 51st call connects with no audio.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Normalization

The dial plan rewrites what a person dialed into a number the routes can match, usually E.164. The first matching rule wins.

Config: Put the specific rules above the general ones.

Fault: A catch-all rule is first, so the emergency rule never runs.

https://learn.microsoft.com/en-us/microsoftteams/create-and-manage-dial-plans accessed 2026-10-14

Tenant dial plan

A set of normalization rules you assign to users. A user can have a more specific plan than the tenant default.

Config: Grant the plan to the user and test from that user.

Fault: You edit the global plan and a branch with its own plan does not change.

https://learn.microsoft.com/en-us/microsoftteams/create-and-manage-dial-plans accessed 2026-10-14

PSTN usage

A name that links a voice routing policy to one or more voice routes. The policy’s ordered list of usages is the permission to place those calls.

Config: Create the usage, attach routes, then put the usage on the policy in the right order.

Fault: International works because the international usage was left on a branch policy.

https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14

Voice route

A number pattern plus an ordered list of SBC gateways. It does nothing until a PSTN usage on the user’s policy points at it.

Config: Anchor the pattern. Test with the normalized number, not the raw digits.

Fault: The route expects 10 digits and the dial plan already added +1.

https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14

Voice routing policy

The per-user list of PSTN usages, in order. Teams walks that order when it looks for a route.

Config: Grant it to a test user and read it back with Get-CsOnlineUser.

Fault: The pilot user is still on the global policy, which has no usages.

https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14

Gateway priority

Each voice route lists SBCs with a priority. Lower priority number is tried first in this campus’s teaching model. Confirm the current article before you depend on a tie.

Config: Put the local SBC first and a remote SBC second, then pull the cable in a maintenance window.

Fault: Both gateways are priority 1 and nobody knows which one took the call.

https://learn.microsoft.com/en-us/microsoftteams/manage-voice-routing-policies accessed 2026-10-14

Emergency short code

999, 112, and 911 must be normalized on purpose. A general rule that runs first can swallow them.

Config: Put emergency rules above catch-alls, and give them a route that is always present.

Fault: A user dials 999 and the dial plan turns it into an extension.

https://learn.microsoft.com/en-us/microsoftteams/what-are-emergency-locations-addresses-and-call-routing accessed 2026-10-14

Auto attendant

A voice app that answers, plays a greeting, and routes by schedule, menu, directory, or operator.

Config: Create the attendant, attach a licensed resource account, then assign a number only if the PSTN must reach it.

Fault: The menu option points at a queue that has no agents and no overflow.

https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-auto-attendant accessed 2026-10-14

Call queue

A voice app that holds callers and offers them to agents by attendant, serial, round robin, or longest idle routing.

Config: Set timeout and overflow before you publish the number.

Fault: The timeout is 3 seconds and callers always overflow.

https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-call-queue accessed 2026-10-14

Conference mode

A queue behavior where the caller stays in the conference while agents are tried, so the transfer is faster and the greeting is not replayed the same way.

Config: Test both modes with a real agent client before you argue about delay.

Fault: Callers hear silence while the queue hunts, and someone disables the queue.

https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-call-queue accessed 2026-10-14

Overflow

Where the call goes when the queue is full or the timeout expires. It can be a person, another voice app, voicemail, or an external number.

Config: Name the overflow in the design, then test it by making every agent busy.

Fault: Overflow to a mobile fails and the queue itself is blamed.

https://learn.microsoft.com/en-us/microsoftteams/aa-cq-reference-prerequisites-licensing accessed 2026-10-14

Directory search

An attendant feature that lets a caller reach a person by name or extension.

Config: Scope who can be found. Do not leave the default if the tenant has privileged accounts.

Fault: A caller reaches an executive because directory search was on.

https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-auto-attendant accessed 2026-10-14

Holiday schedule

A calendar the attendant uses to play the closed greeting. It is not the same object as business hours.

Config: Load the next year’s holidays when you build the attendant.

Fault: The office is closed and the attendant still hunts the queue.

https://learn.microsoft.com/en-us/microsoftteams/create-a-phone-system-auto-attendant accessed 2026-10-14

Dynamic emergency calling

Teams picks a civic address from the network location it can see: trusted IP, site, and subnet in the usual design.

Config: Build the topology, assign addresses, and test from a known subnet.

Fault: A laptop on the VPN reports the HQ floor.

Civic address

The street address you validate for emergency calling. A dispatchable location is specific enough for responders.

Config: Validate the address and tie subnets to places inside it.

Fault: The PSAP gets a city and no building.

Trusted IP

An address that means ‘this client is inside our network.’ It is how Teams decides the client is on a site you mapped.

Config: List the real internet egress addresses, not the VPN pool, unless you mean to.

Fault: Remote users inherit a building.

https://learn.microsoft.com/en-us/microsoftteams/what-are-emergency-locations-addresses-and-call-routing accessed 2026-10-14

Emergency calling policy

Controls notification and how the client looks up location. It is not the PSTN route.

Config: Pair the policy with a routing policy and a tested number from the carrier.

Fault: Security is notified for a test call and the route still left the country.

Direct Routing emergency

You, the SBC, and the carrier deliver the emergency call. Microsoft does not become the emergency carrier because Teams is the client.

Calling Plan emergency

With Microsoft Calling Plans in supported countries, Microsoft’s emergency calling service is part of the plan. You still configure locations.

Fault: A Calling Plan user is sent to your SBC for 911 by a copied route.

Location-based routing

Stops a user in a regulated site from placing a PSTN call through a gateway in another site. It is a toll-bypass control.

Config: Enable it per site with the network topology and the gateways that belong there.

Fault: A traveler’s laptop in one country egresses through another country’s SBC.

https://learn.microsoft.com/en-us/microsoftteams/location-based-routing-plan accessed 2026-10-14

Survivable Branch Appliance

A Direct Routing appliance that can keep local PSTN calling when the branch cannot reach Microsoft 365.

Media bypass

Media can flow between the Teams client and the SBC, skipping Microsoft’s media processors. Signaling still goes through Teams.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Local media optimization

A Direct Routing pattern with internal and external SBC interfaces so a branch user stays on the local media path.

Fault: Internal users hairpin out to the internet and back to the SBC on the same LAN.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

SIP Gateway

Microsoft’s front end for certain compatible analog and SIP devices that are not Teams phones.

Teams-certified phone

A handset in Microsoft’s certified device program, signing in as a Teams user.

SRTP

The media encryption Direct Routing uses. Signaling is TLS. A successful INVITE with plaintext RTP is not the design.

Config: Allow the UDP media range. Do not strip SRTP on the SBC.

Fault: The SBC offers RTP/AVP only and the call fails or is unsupported.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

TLS 1.2

Direct Routing signaling expects modern TLS. TLS 1.0 is not a compatible offer.

Config: Upgrade firmware and offer TLS 1.2 or newer toward the proxies.

Fault: The handshake dies before OPTIONS.

https://learn.microsoft.com/en-us/microsoftteams/direct-routing-plan accessed 2026-10-14

Certificate SAN
